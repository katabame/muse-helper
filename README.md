# Muse Helper

[Muse](https://muse.ai) (muse.ai) のデスクトップ Web 版に、次の表示を追加する Chrome 拡張機能です。

- **週間使用率バッジ**: 残りの週間トークン(%)とリセット日を画面右上に表示します(ドラッグで移動可、位置は保存されます)。
  設定画面の「一般」(利用状況)を一度開くと、以降はページを開くだけで5分ごとに自動で更新されます(タブが裏にあっても更新し、複数のタブで開いているときは1つのタブだけが取得します)(最後に取得した値を保存し、「◯分前」を併記します)。
  クリックすると「57%」だけの縮小表示に切り替わります(もう一度クリックで元に戻ります)。
- **使用ペースの予測**: 週の経過に対する目安との比較、週の始まりからの平均ペース、直近24時間のペースの3通りで、リセット時の使用率や上限に達する時刻を予測します。バッジに要約を、設定画面の「Muse Helper」項目に詳細と今週の使用率の推移グラフを表示します。リセット前に上限に達しそうなときは、グラフの上に「○日○時ごろ上限」と表示し、グラフにもその時刻の縦線とリセットまでの期間を示します。
- **使用率の通知**: 残りが20%以下になったときと、このペースだとリセット前に上限に達しそうなときに、Chrome の通知でお知らせします(それぞれ週に1回。設定画面でオフにできます)。
- **リセットの通知**: 週の使用率がリセットされたら通知します。muse.ai のタブを閉じていても届きます(正確なリセット日時が分かっているときだけ)。
- **返信の通知**: 別のタブやアプリを見ている間に相手の返信が書き終わったら通知し、通知を押すとそのタブを開きます。本文の冒頭を通知に出すかどうかも選べます(既定は出しません)。
- **利用の記録**: 送ったメッセージと届いた返信を日ごとに数え、設定画面に直近28日の棒グラフと、今日・直近7日・直近28日の件数、よく送る曜日と時間帯の表を表示します。
- **文字数カウンター**: チャットの入力欄の右上に、入力中の文字数を表示します(絵文字も1文字として数えます)。
- **下書きの自動保存**: 入力中の文章をチャットごとに自動保存し、入力欄が空のときに表示される「下書きを復元」ボタンで戻せます(送信すると削除、30日で自動削除)。送信以外で消えた下書き(全部消した・✕で破棄した)は「以前の下書き」としてチャットごとに5件まで残り、そこから戻せます。設定画面の「Muse Helper」項目でオン/オフと一括削除ができます。
  - **下書きの一覧**(`Alt+R`、または設定画面の「下書き」→「一覧を開く」): すべての会話の下書きを会話ごとに新しい順で表示します。項目を押すとその会話を開いて(再読み込みせずに)入力欄に戻します。✕ で削除、本文・会話名で絞り込みができ、「以前の下書き」も会話ごとに開いて戻せます。
- **メッセージの時刻**: 各メッセージの下に送信時刻を表示します(自分のメッセージは右寄せ)。
  muse.ai の設定画面に追加される「Muse Helper」項目から、表示内容(時刻のみ / 相対時刻のみ / 時刻と相対時刻)と、24時間表記(`15:05`)/ 12時間表記(`3:05 pm`)を切り替えられます。
  「相対時刻のみ」では、7日以上前のメッセージは日付と時刻で表示します。
  日付が変わるところには「── 11月23日(月) ──」の区切り線を、相手の返信には「・12秒で応答」のように応答時間を添えます(どちらも設定でオフにできます)。
- **送信キーの切り替え**: 「Enter で送信」(Muse の標準)と「Ctrl/⌘+Enter で送信(Enter で改行)」を設定画面で選べます。
- **残りが少ないときの送信前の確認**: 使用率の残りが設定の値(既定 10%)以下のとき、送信の前に「残り 8% です。送信しますか？」と確認します(送ったあと30分は聞きません)。
- **表示の調整**: 本文の幅(狭い / 標準 / 広い / 画面いっぱい)と文字の大きさ(80〜125%)を変えられます。長いメッセージを途中まで表示して「全文を表示」で開く折りたたみ(既定はオフ)もあります。
- **会話の統計**: 設定画面の「Muse Helper」→「この会話」に、表示中の会話のメッセージ数・文字数(自分/相手)・応答時間(中央値・平均・最短・最長)・期間を表示します。
- **メッセージのブックマーク**: メッセージにマウスを乗せ、時刻の横の ☆ を押すと保存します。一覧(`Alt+B`、または設定画面から)の項目を押すと、そのメッセージへ移動します(別の会話なら開いてから移動します)。一覧の鉛筆ボタンでメモを付けられ、本文・メモ・会話名で絞り込んだり、会話ごと / 追加した順で並べ替えたりできます。サイドバーの会話の名前の横には「★2」のように件数を表示します(設定でオフにできます)。
  - 本文は書式(見出し・リスト・太字・コード・表・リンクなど)ごと保存するので、まだ読み込まれていないメッセージでも、一覧の「全文を表示」ボタンでパネルの中に全文を表示できます。
  - 読み込まれていないメッセージへ移動するときは、見つかるまで会話を上へ自動で読み込みます(設定の「過去のメッセージを自動で読み込んで移動」でオフにできます)。オフのときや見つからなかったときは全文を表示します。
- **会話内の検索**: `Alt+S` で検索バーを出し、読み込まれているメッセージの中から探します。自分/相手のメッセージだけに絞り込めます(`Enter` で次、`Shift+Enter` で前)。
- **定型文**: 設定画面の「定型文」で登録しておき、`Alt+T` で一覧を出して選ぶと、入力欄のカーソル位置に挿入します。文中の `{日付}` `{時刻}` `{曜日}` `{選択中の文字}` `{クリップボード}` は挿入時に中身に置き換わり、`{カーソル}` の位置にカーソルを置きます。
- **バックアップ**: 設定画面の「バックアップ」で、設定・使用率の記録・下書き・ブックマーク・定型文・利用の記録を JSON ファイルに書き出し、読み込めます。
- **キーボードショートカット**: `Alt`(Mac は `Option`)と組み合わせて使います。設定画面でキーを変えたり、オフにしたりできます(以下は既定のキー)。

  | キー | 動作 |
  |---|---|
  | `Alt+I` | 入力欄にフォーカス |
  | `Alt+J` | 最新のメッセージへ |
  | `Alt+↑` / `Alt+↓` | 前 / 次のメッセージへ(入力欄に文章があるときは入力欄の中の移動) |
  | `Alt+S` | 会話内を検索 |
  | `Alt+T` | 定型文を挿入 |
  | `Alt+B` | ブックマークの一覧を開く / 閉じる |
  | `Alt+R` | 下書きの一覧を開く / 閉じる |
  | `Alt+/` | ショートカットの一覧を表示 |

- **アップデート通知**: GitHub Releases に新しいバージョンがあると、使用率バッジと設定画面の「Muse Helper」項目でお知らせします(1時間ごとに確認)。インストールしたフォルダのファイルが新しくなっていれば(git pull や zip の上書き)、「再読み込みして更新」ボタンで拡張機能と muse.ai のタブをまとめて新しい版にできます。
- **デベロッパーモード**: 設定画面の「Muse Helper」→「開発者向け」でオンにすると、診断情報・画面の構造・Muse の React Query キャッシュの一覧などをワンクリックでコピーできます。DevTools の Console では `museHelper.help()` で使い方を表示できます(調査用。ID らしき部分は伏せてコピーします)。

## インストール

1. [Releases の最新版](https://github.com/katabame/muse-helper/releases/latest)を開き、**Source code (zip)** をダウンロードします。
2. zip を展開し、できたフォルダを置いておく場所(例: `ドキュメント/muse-helper`)に移します。
   Chrome はこのフォルダから直接読み込むため、インストール後もフォルダは削除・移動しないでください。
3. `chrome://extensions` を開き、右上の「デベロッパーモード」をオンにします。
4. 「パッケージ化されていない拡張機能を読み込む」を押し、手順 2 のフォルダ(`manifest.json` が入っているフォルダ)を選びます。
5. muse.ai のタブを再読み込みします。

## 更新

新しいバージョンが出ると、使用率バッジと設定画面の「Muse Helper」項目でお知らせします。

1. [Releases の最新版](https://github.com/katabame/muse-helper/releases/latest)から **Source code (zip)** をダウンロードして展開します。
2. インストールしたフォルダの中身を、展開したファイルで上書きします。
   設定・下書き・使用率の記録を引き継ぐため、**同じフォルダ**に上書きしてください(別のフォルダから読み込むと別の拡張機能として扱われ、保存したデータは引き継がれません)。
3. 使用率バッジの「⬆ v0.x.x に更新 — クリックで再読み込み」、または設定画面の「Muse Helper」→「アップデート」の「再読み込みして更新」を押します。
   拡張機能が再読み込みされ、開いている muse.ai のタブもすべて読み込み直されます(フォルダは muse.ai のタブを表示している間1.5秒ごとに確認するので、上書きすると数秒で出ます)。
   ボタンが使えない場合(v0.7.3 以前からの更新など)は、`chrome://extensions` で Muse Helper の再読み込みボタン(↻)を押し、muse.ai のタブを再読み込みします。

開発中の最新のコードを使う場合は、Releases の代わりにこのリポジトリを `git clone` して、同じ手順で読み込んでください。`git clone` で入れた場合は、手順 1〜2 の代わりに `git pull` でフォルダを新しくできます。

## 仕組みと制約

- Muse のチャット通信は暗号化されているため、通信は読んでいません。
- 使用率は、Muse の React Query キャッシュにある `["subscription", <ユーザーID>, "agreement"]` クエリ(`usage.percentUsed` / `usage.resetsAt` など)から読み取っています(`usage-main.js`、MAIN world で動作)。
  このクエリは設定画面を開いたときに初めて作られるため、その取得処理を覚えておき、以降は `queryClient.fetchQuery` で5分ごとに取り直しています。タブが裏にあっても取り直し、最後に取得を試みた時刻を localStorage(`museHelperUsageFetchAt`)でタブ間に共有して、複数のタブから重ねて取りに行かないようにしています(裏のタブのタイマーは Chrome により1分に1回程度に間引かれることがあります)。
  あわせて、その取得で使われた Next.js のサーバーアクションの呼び出し(`Next-Action` ヘッダーと引数)を muse.ai の localStorage(`museHelperUsageAction`)に覚えておき、ページを開き直したあとは設定画面を開かなくても同じ呼び出しで取り直します。Muse の更新でアクションが変わって2回続けて失敗したときは「自動更新は停止中」になるので、設定画面の「一般」を一度開くと覚え直します。
  内部データが取れないときは、設定画面の `role="progressbar"` (`aria-valuenow`) と周辺のテキストを DOM から読み取ります(`content.js`)。
- 設定画面の「Muse Helper」項目は、設定ダイアログ(見出し「設定」の `role="dialog"`)を検出し、サイドバーと右ペインに要素を差し込んで表示しています(`settings.js`。グラフは `settings-charts.js`)。
- メッセージ時刻は、React の内部データ(メッセージ要素の fiber に保持された `createdAt`)から読み取っています(`timestamps.js`、MAIN world で動作)。
- 会話の統計・ブックマーク・ショートカットは、画面に読み込まれているメッセージ(`data-message-id` を持つ要素)と、`timestamps.js` が付けた時刻を使います。Muse がまだ読み込んでいない古いメッセージは、統計に含まれません。ブックマークからの移動では、会話の一覧を一番上までスクロールして Muse に過去のメッセージを読み込ませ、見つかるまで繰り返します(6秒続けて増えなければ打ち切り)。
- ブックマークの本文は、許可したタグだけの木構造(JSON)にして保存し、表示するときは `createElement` で組み立て直します(HTML の文字列は使いません。リンクは http/https のみ)。v0.7.1 以前に保存したブックマークは冒頭160文字だけなので、そのメッセージが画面に読み込まれたときに全文へ入れ替えます。保存量が増えるため `unlimitedStorage` 権限を使います。
- 利用の記録と返信の通知は、このタブで新しく表示されたメッセージのうち送信時刻が5分以内のものを対象にし、本文が数秒変わらなくなったら書き終わったとみなします(`activity.js`)。muse.ai を開いていない間のメッセージは数えません。
- サイドバーの会話の行は会話の ID を持たないため、会話を開いたときに「開いている行の名前」と URL のパスを組にして覚え、名前で行を見分けて ★ の件数を出しています。名前を変えた会話は、もう一度開くと表示が戻ります。
- 別の会話のブックマークへの移動は、Muse(Next.js)の `window.next.router.push` で画面を切り替えています(`nav-main.js`、MAIN world で動作)。使えないときはページを読み込み直して移動します。
- 会話内の検索は、CSS Custom Highlight API で色を付けるため、Muse の画面に要素を足しません(`search.js`)。
- 使用ペースの予測は、利用状況を読み取るたびに使用率を記録し(値が変わったとき、または15分ごと。14日分を保持)、その記録から計算しています(`common.js` の `forecast`)。
- アップデート確認は、service worker(`background.js`)が1時間ごとに GitHub API の `releases/latest` を取得し、タグ(例: `v0.4.0`)を `manifest.json` の `version` と比較しています。リリースのタグは `v<version>` の形式にしてください。
- 画面の「相手」の表記(ブックマーク・会話の統計・検索の範囲・返信の通知・リアクションの説明など)には、アシスタントの名前を使います。名前は Muse の画面上部のアバター(`data-hatch-avatar-accessory="status-pill"` の `aria-label`)から覚えて `museAssistantName` に保存します(分からないうちは「相手」)。
- リアクションの絵文字にマウスを乗せると、絵文字を大きく表示し、日本語の名前を添えたツールチップを出します(`reactions.js`)。名前は Unicode CLDR の日本語の読み上げ名から作った `emoji-ja.json` を使います(ライセンスは `THIRD_PARTY_NOTICES.md`)。
- Muse Helper の表示の説明(ツールチップ)は、Chrome 標準のもの(`title` 属性)だと OS のフォントで描かれ、環境によって漢字が中国語の字形になるため、`tooltip.js` が `title` を `data-muse-tip` に移して自前で表示しています(日本語のフォントを優先、`lang="ja"`)。
- 「再読み込みして更新」は、パッケージ化されていない拡張機能(`chrome.management.getSelf()` の `installType` が `development`)のときだけ使えます。service worker が拡張機能のフォルダの `manifest.json` を `fetch(chrome.runtime.getURL('manifest.json'))` で読み、今動いている版より新しければボタンを出します。フォルダの確認は GitHub の確認(1時間ごと)とは別に、muse.ai のタブを表示している間1.5秒ごとと、ページを開いたとき(`content.js` からのメッセージ)、1分ごと(`chrome.alarms`)に行い、変わったときだけ保存します(ストアからインストールした場合は行いません)。押すと `chrome.runtime.reload()` で再読み込みします。
- 拡張機能が再読み込み・更新されると、開いている muse.ai のタブの古いスクリプトが、入力中の文章を預けてタブを読み込み直します(`content.js` の `orphanCheck`)。古いスクリプトからは無効化・削除も同じに見えるため、ページから読めるように公開したアイコン(`web_accessible_resources` の `icons/icon16.png`)を読み込めるか(= 拡張機能が動いているか)を確かめ、読めるときだけ読み込み直します(無効化したときはタブをそのままにします)。
- いずれの機能も Muse の画面や内部実装に依存するため、Muse 側の更新で動かなくなる可能性があります。
