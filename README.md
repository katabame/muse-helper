# Muse Helper

[Muse](https://muse.ai) (muse.ai) のデスクトップ Web 版に、次の表示を追加する Chrome 拡張機能です。

- **週間使用率バッジ**: 残りの週間トークン(%)とリセット日を画面右上に表示します(ドラッグで移動可、位置は保存されます)。
  値は設定画面の「利用状況」を開いたときに更新されます(最後に取得した値を保存し、「◯分前」を併記します)。
- **使用ペースの予測**: 週の経過に対する目安との比較、週の始まりからの平均ペース、直近24時間のペースの3通りで、リセット時の使用率や上限に達する時刻を予測します。バッジに要約を、設定画面の「Muse Helper」項目に詳細を表示します(リセット時刻は 0:00 と仮定)。
- **文字数カウンター**: チャットの入力欄の右上に、入力中の文字数を表示します(絵文字も1文字として数えます)。
- **下書きの自動保存**: 入力中の文章をチャットごとに自動保存し、入力欄が空のときに表示される「下書きを復元」ボタンで戻せます(送信すると削除、30日で自動削除)。設定画面の「Muse Helper」項目でオン/オフと一括削除ができます。
- **メッセージの時刻**: 各メッセージの下に送信時刻を表示します(自分のメッセージは右寄せ)。
  muse.ai の設定画面に追加される「Muse Helper」項目から、表示内容(時刻のみ / 相対時刻のみ / 時刻と相対時刻)と、24時間表記(`15:05`)/ 12時間表記(`3:05 pm`)を切り替えられます。
  「相対時刻のみ」では、7日以上前のメッセージは日付と時刻で表示します。

- **アップデート通知**: GitHub Releases に新しいバージョンがあると、使用率バッジと設定画面の「Muse Helper」項目でお知らせします(1時間ごとに確認)。

## インストール

1. このリポジトリをダウンロード(または clone)します。
2. `chrome://extensions` を開き、「デベロッパーモード」をオンにします。
3. 「パッケージ化されていない拡張機能を読み込む」でこのフォルダを選びます。
4. muse.ai のタブを再読み込みします。

## 仕組みと制約

- Muse のチャット通信は暗号化されているため、通信は読んでいません。
- 使用率は、設定画面の `role="progressbar"` (`aria-valuenow`) と周辺のテキストを DOM から読み取っています(`content.js`)。
- 設定画面の「Muse Helper」項目は、設定ダイアログ(見出し「設定」の `role="dialog"`)を検出し、サイドバーと右ペインに要素を差し込んで表示しています(`settings.js`)。
- メッセージ時刻は、React の内部データ(メッセージ要素の fiber に保持された `createdAt`)から読み取っています(`timestamps.js`、MAIN world で動作)。
- 使用ペースの予測は、利用状況を読み取るたびに使用率を記録し(値が変わったとき、または15分ごと。14日分を保持)、その記録から計算しています(`common.js` の `forecast`)。
- アップデート確認は、service worker(`background.js`)が1時間ごとに GitHub API の `releases/latest` を取得し、タグ(例: `v0.4.0`)を `manifest.json` の `version` と比較しています。リリースのタグは `v<version>` の形式にしてください。
- どちらも Muse の画面や内部実装に依存するため、Muse 側の更新で動かなくなる可能性があります。
